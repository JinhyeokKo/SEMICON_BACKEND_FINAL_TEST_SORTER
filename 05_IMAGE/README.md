# README와 발표용 이미지

프로젝트 소개에 사용하는 자체 시험 화면의 복사본을 보관한다. 시험 당시 증거 원본과 식별 정보는 `06_TEST/04_EVIDENCE` 및 시험 원장의 증거목록에 유지한다.

## 소개 화면과 시험 원본

SCADA의 주요 5개 페이지와 LabVIEW 검사 운영 화면, 총 6개를 루트 README에 연결한다. 메인 운전과 LabVIEW는 바로 표시하고 나머지 SCADA 페이지는 펼쳐서 볼 수 있다.

| 소개용 파일 | 보여주는 내용 | 실제 시험 원본 |
|---|---|---|
| [메인 운전 화면](readme/screenshots/main_operation.png) | 공정 상태와 분류 및 완료 수량 | `06_TEST/04_EVIDENCE/RUN-20261017-01/screens/P02_02_counts.png` |
| [검사 이력 화면](readme/screenshots/inspection_history.png) | 최근 검사 결과 조회 | `06_TEST/04_EVIDENCE/RUN-20261017-01/screens/AE05_02_first_load.png` |
| [센서 중계 화면](readme/screenshots/sensor_bridge.png) | 실측 센서 전달과 중계 상태 | `06_TEST/04_EVIDENCE/RUN-20261017-01/screens/AE11_20min_sensor.png` |
| [알람 이력 화면](readme/screenshots/alarm_history.png) | 알람 발생·해제·인식 이력과 복구 상태 | `06_TEST/04_EVIDENCE/RUN-20261017-01/screens/P07_06_alarm_after_reset.png` |

이 화면들은 해당 시험에서 캡처한 관측 자료다. 실물 컨베이어 운전, 실제 반도체의 전기 측정 또는 장기 무중단 운전 인증을 보여주는 사진은 아니다. 상세 조건과 합격 판정 범위는 [시험 자료](../06_TEST/README.md)를 확인한다.

이미지를 추가 편집하거나 크기를 바꿀 때는 소개용 사본에 적용하고 시험 원본은 별도로 보관한다. 외부 제품 사진이나 제조사 도해를 추가하는 경우 자체 시험 캡처와 구분하고 출처를 함께 적는다.
