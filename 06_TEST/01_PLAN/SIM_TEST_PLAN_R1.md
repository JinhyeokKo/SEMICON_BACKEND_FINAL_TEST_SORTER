# 시뮬레이션 통합 기능 시험 계획 R1

작성일: 2026-10-15. 실제 수행일·수행자·판정은 실행기록에 별도 입력한다.

## 목적과 범위

현재 성공본의 공정·분류·계수, 단발/연속, 안전 신호 모사, 고장 감시, 실측 ESP 센서 전달, FX 환경 판정, LS 시작 허가, 가상ATE 수락·CSV·조회, 통신 단절·수동 복구와 정상 종료를 시험한다.

LS·FX·기계는 시뮬레이션이다. SEN0137/ESP32의 온습도·Wi-Fi 통신은 실물이다. 실제 PLC·모터·판넬 시공·PCT·현장SAT·안전 성능·고객 인수는 범위에서 제외한다. P101~P105는 개념 설계로 보관한다.

## 시험 기준과 변경

현재 성공한 프로젝트를 BL-001로 보관한다. 기준값과 이번 관측값을 분리한다. 소스·주소·동작 정책·통신 설정 변경은 새 기준선과 영향 시험 재실행으로 관리한다. 기존 정상 normal_v01/500ms 성공 설정을 유지한다. 타임아웃 단축이나 허가 강제는 하지 않는다.

## 진입 조건

- 프로그램·설정·DWG/PDF 저장 및 기준설정 기록.
- 새 RunID·증거 폴더·존재하는 CSV 부모 폴더·새 파일명 준비.
- SIM_IO→MAIN, 정상 원시 조건, 안전 복귀·공정RESET·LS10/알람0.
- 실측 환경 복귀 범위와 새 정상5회, 두 중계 정상·환경허가ON.
- ATE_READY/PLC_LIVE_OK 정상. 준비조건 미달은 보류하고 이유를 기록.

## 실행과 기록

guide_ko.html과 02_PROCEDURE/SIM_TEST_PROCEDURES_R1.md를 따른다. 필수25개·선택2개이다. P02/P03/P04 뒤 경계제품2개만 추가해 정상5건 CSV·최근5건을 확인한다. AE03/04/07은 각각P03/04/P09로 통합되어 중복 실행하지 않는다. ATE 수락 CSV와 배출완료 누계의 시점 차이를 유지한다.

실행원장은 03_RECORD/SIM_TEST_RECORD_R1.xlsx 하나다. 실제 관측·시각·기준선·ID·대표 증거를 입력한다. 재시험은 새 행·새 실행ID로 추가한다. 문제 상태와 시험 합격 판정을 분리한다. 실제 결과가 없는 기존 성공 보고를 새 시험의 합격으로 전사하지 않는다.

## 종료 조건

필수 시험을 실제 수행하여 기대 동작과 증거가 일치하고, 실패·보류 사유와 영향이 검토되어야 한다. 정상 지속운전의 목표는 같은 구성 30분 이상이며, 제품 신뢰성 인증 기준이 아니다. 중간 오류 시 실패 실행을 보존하고 재시험은 새 RunID로 시작한다. 현재 간헐 OPC/중계/종료 문제는 재발 여부와 원인을 확인하며 추정 원인으로 닫지 않는다.

도면22장에 실제 도면번호를 매핑하고 최신 구현·시험·원장을 대조한다. R116에 실제 증거를 연결하고, 작성자 자체 검토 후 최종DWG/PDF/결과요약을 같은 개정으로 발행한다. 참여하지 않은 고객·검토자의 승인을 작성하지 않는다.
