## P01 초기 RUN과 안전 복귀·모델 정리·RESET의 역할 구분
필수 / 02 기동·준비 / 도면: R103, R104, R106, R114, R116

### 시작 전
- 최종 성공본 LS 프로젝트(스캔 순서 SIM_IO→MAIN)·FX·CIMON·LabVIEW 버전을 식별해 저장한다.
- 현재 생산량·CSV를 보관한다. PLC RUN 재시작은 생산량을 초기화한다.
- 첫 실행 순간에는 공정 START를 누르지 않는다.

### 조작과 확인
1. LS를 RUN한 직후 D01220=0·M02100=0·D01200=0, M02001=1·M02000=0, M02023/M01000=0을 읽고 화면을 남긴다.
2. 원시 정상 M02022=1을 확인한 뒤 안전 복귀M02002를 새로 누르고 놓는다. M01000=1이 되어도 D00100=0·D00310=1이 남는지 본다.
3. 빈 장치 조건 M00063=1과 환경 허가를 준비하고 공정 RESET M00202를 새로 누른다. LS10·알람0을 확인한다.  LabVIEW를 Run해 ATE_READY까지 확인한다. 
4. 20초 동안 START를 누르지 않는다. 모델0·공정10·계수 불변을 확인한다. 

### 합격 기준
- 초기 RUN은 자동 기동하지 않는다. 가상 안전 허가는 수동 복귀로만 켜진다.
- 안전 복귀와 공정 RESET의 역할이 구분된다. 준비 후LS10/알람0/READY, 새 START 전 대기한다.

## AE01 실측 센서→FX→LS 및 ATE 준비 상태
필수 / 02 기동·준비 / 도면: R102, R107, R109, R110, R111, R112, R115, R116

### 시작 전
- 공통 준비 조건을 수행한다.
- 실내 환경이 복귀범위에 들어오지 않으면 허가 ON을 만들지 말고 조건미충족으로 남긴다.

### 조작과 확인
1. ESP Monitor에서 BOOT/SEQ/temp/rh/valid/status/age 로그를 저장하고 SENSOR 페이지를 연다. 확인: 실측 valid1/status0, SEQ가 새 측정마다 증가한다. 원시 온습도×100과 실제표시÷100 단위를 확인한다. 
2. 환경 중계를 시작해 FX/LS 자료 정상 확인 후 센서 중계를 시작한다. 최소 새 정상SEQ5회를 관찰한다. 확인: 두 중계RUN1/오류0, 이번 실행ACK 횟수가 증가, FX D3/D4가 실측온습도, M0=0, D32가 정상복귀 횟수, M100=1/D34=0, LS M0100C=1.
3. SAFETY 정상 복구·공정RESET 후 LabVIEW를 새 CSV 경로로 Run한다. 확인: LS10/알람0/모델0, ATE_READY/PLC_LIVE_OK=True, D00030 증가, START 전 공정요청0·생산량 불변.
4. 같은 화면을 약5초 간격으로 두 번 저장한다. 확인: 고정된 ACK숫자 하나가 아니라 이번실행ACK/SEQ/생존카운터가 계속 갱신된다.

### 합격 기준
- 실측 값이 FX 적용 ACK까지 전달되고 LS 시작 허가와 ATE 준비가 모두 정상이다.
- 정지된 캐시값만으로 통신정상을 판정하지 않는다.

## P02 단발 PASS 한 제품의 검사 수락·자동 분류·배출·계수
필수 / 03 정상 5건·이력 / 도면: R105, R107, R108, R114, R115, R116

### 시작 전
- BASE 완료. D00053=0 Auto·D01220=0 단발.
- 실행 중인 CSV 경로와 검사 전 누계/데이터 행 수를 기록한다. 
- 새 START 전에 LabVIEW AutoVoltage=True, SimVoltage_mV=3300, Low_mV=3000, High_mV=3600.

### 조작과 확인
1. CIMON 공정 START M00200을 한 번 눌렀다 놓는다. M01004~M0100B를 손으로 조작하지 않고 자동 진행을 관찰한다.
2. LS20→30→50→60으로 진행하는 장면을 동영상으로 남긴다. 한 스캔 상태40이 화면에 안 보여도 실패로 판정하지 않는다.
3. 검사 수락 뒤 D00102=1, D00029=이번 요청 ID를 확인한다.  선택 분류는state81, M01103/M01009 명령/도달 대응으로 확인한다.  짧은 D00020 값은 필수 캡처가 아니다.
4. LS90→100→110→10, 제품 모델40→가상 수거→0까지 자동 진행을 기다린다. 짧은110은 누계 증가로 확인한다. 
5. LS10·모델0에서20초 대기한다. 추가 계수/새 제품/요청 ID 증가가 없어야 한다. CIMON 검사 화면에서 같은 CSV를 다시 불러와 결과/ID를 비교한다.

### 합격 기준
- 검사 수락결과1와 request_id=accepted_id. PASS 분류만 선택된다.
- Total+1, PASS+1, 다른 결과별 생산량 변화0. CSV 데이터 행+1, mode=AUTO, result_code=1.
- 검사 후 D00020/21/25는 정상 정리될 수 있다. D00102는 다음 제품 시작/중단 전까지 유지된다.
- 단발은 완료·수거 후 새 START를 기다린다. RETEST는 분류함이며 자동 재검사 루프가 아니다.

## AE02 가상 전압 하한·상한 PASS 두 건 추가
필수 / 03 정상 5건·이력 / 도면: R105, R107, R108, R113, R114, R115

### 시작 전
- P02(3300 PASS), P03(2900 FAIL), P04(MANUAL RETEST)를 같은 새 CSV 실행에서 완료했다.
- LabVIEW와 같은 CSV를 유지한다. PLC는 Auto·단발, LS10/모델0/ATE_READY/환경허가 ON.

### 조작과 확인
1. LabVIEW AutoVoltage=True, Low_mV=3000, High_mV=3600, SimVoltage_mV=3000으로 설정한다. 아직 START를 누르지 않는다.
2. 설정 화면을 저장한 뒤 START를 한 번 눌렀다가 놓는다. 완료·수거 뒤 D00102=1, D00029=이번 요청ID, Total/PASS 각각 +1을 기록한다. 
3. LS10/모델0/ATE_READY를 확인하고 전압만 3600으로 바꾼다. START 1회 후 같은 판정·분류·수량 증가를 기록한다. 
4. AutoVoltage=True, 전압3300으로 복원한다. 새 START 없이 대기하고 AE05로 진행한다.

### 합격 기준
- 3000과 3600은 모두 경계 포함 PASS(결과1)다. 각 요청ID=수락ID, CSV는 각각 한 행이다.
- P02·P03·P04와 합쳐 새 제품은 5개다. 모두 완료했다면 ΔTotal=5, ΔPASS=3, ΔFAIL=1, ΔRETEST=1.

### 남길 증거
- AE02_01_3000_PASS.png
- AE02_02_3600_PASS.png
- 같은 실행의 원본 CSV와 각 요청/수락ID

### 복원
- 전압3300으로 복원하고 같은 CSV로 AE05 조회를 한다.

### 메모
- 3300 제품은 P02의 실제 기록을 참조한다. AE03/AE04는 각각 P03/P04로 통합했고, AE07은 P09로 통합했다. 번호가 비어 있어도 누락이 아니다.

## AE05 CSV 1수락1행·최근5건 조회·반복조회
필수 / 03 정상 5건·이력 / 도면: R107, R108, R115, R116

### 시작 전
- P02/P03/P04 기본3건과 AE02경계2건을 완료한뒤 LS10/모델0. 같은실행의새 CSV5건을사용한다.
- 중간오류/다른제품/재실행이있었다면그기록을보존하고, 조회대상전체행 수/최근5건을실제 실행기록과비교한다. 행을삭제해5건으로맞추지않는다.

### 조작과 확인
1. LabVIEW가 닫고기록한 원본 CSV를 복사하여 메모장으로 읽는다. 원본을편집·저장하지않는다. 확인: 헤더1줄/데이터5줄.9필드. request_id=accepted_id. captured_utc와accepted_utc/Z. 헤더반복·중복행없음.
2. 각ID를 P02·P03·P04·AE02의기록과대조한다. 확인: 다섯필수기록: AUTO3300/P1, AUTO3000/P1, AUTO3600/P1, AUTO2900/F2, MANUAL빈측정필드/R3. 실제 실행 순서를 원본 CSV와대조한다.
3. CIMON INSPECTION에서같은 CSV 전체경로를입력하고 결과불러오기를1회누른다. 확인: INSP_VALID1/오류0/기록수5. 원본 CSV마지막행부터역순으로최근5건/ID일치. P02→P03→P04→3000→3600 순이면 위에서3600PASS→3000PASS→RETEST→FAIL→3300PASS이다.

## P09 환경 시작 허가 OFF에서 현사이클 마무리·새 START 차단

### 시작 전

### 조작과 확인
1. 빈 LS10에서 D01220=1 연속을 선택한다. M02010=1을 먼저 설정한 뒤 START를 한 번 누르고 놓는다. LS30에서 M02100=1을 확인한다.

## FX01 FX 환경 경계·히스테리시스 단독 모의시험
선택 / 선택 / 도면: R110, R111, R116

### 시작 전
- 현재성공본에도M0모의분기와D10/D11/D13~D16입력경로가존재함을래더에서먼저확인한다.  이전가이드의옛T0/AGE시간값을적용하지않는다. 경로가확인되지않으면NOT_RUN/검토필요.
- 실측온습도를인위적으로바꾸지않고환경판정회로를입증해야할때만별도모의실행으로수행한다. 실제센서통합PASS와구분한다.

### 조작과 확인
1. LS10/단발/연속기억0, LabVIEW정지, 센서 중계정지→환경 중계정지/RUN0. LS허가 OFF확인.
2. 현재M0/D10/D11/D13~D16값과설정을백업한다. 모의입력임을영상/파일명에표시한다.
3. GX모니터로M0=1/M1=0/M2=0/D10=1/D11=1/D13=2500/D14=5000/D15=1/D16=0. 판정임계값이나프로그램코드는변경하지않는다.
4. FXO01 입력: 정상2500/5000 / 확인: 새정상D2가서로다르게5번들어와D32=5→M100=1/D34=0. 같은순번반복읽기는복귀누적아님.
5. FXO02 입력: 정상허가뒤D13=3100→2950→2500 / 확인: 31°C에서M1000/코드2,29.5°C는유지범위이나복귀범위밖이라허가0/코드1,25°C새정상5회뒤복귀.
6. FXO03 입력: 정상허가뒤D14=7500→6800→6500 / 확인: 75%에서M1000/코드3,68%에서복귀대기0/코드1,65%경계새정상5회뒤허가1.
7. FXO04 입력: 허가성립상태D13=3000/D14=7000. 그뒤별도차단후D13=2900/D14=6500으로복귀 / 확인: 허가 ON이면유지상한30°C/70%포함.차단후복귀상한29°C/65%포함새정상5회.경계방식을임계값변경으로시험하지않음.

### 합격 기준
- 복귀 5개 새 샘플, 유지·복귀 경계와 재허가 동작이 저장된 기준과 일치한다.
- 모의 입력 증거로 구분하고 실측 모드로 복원한다.

### 남길 증거
- 모의 입력 설정/각 경계 판정/새 SEQ5회/실측 복원 캡처. 코드 변경이나 실제 온습도 범위 이탈의 증거로 쓰지 않는다.

### 복원
- D13/D14 등 모의 입력 변경을 원래 백업값으로 복원→M0=0 실측 선택. M1/M2=0.
- 환경 중계→센서 중계 시작→실측 D3/D4/ACK/실제 조건 새 정상5회/LS 허가를 확인한다. 
- 새 CSV의 LabVIEW를 복구하고 PLC 새 START 전 정지를 확인한다. 

### 메모
- 센서/환경 중계를 모두 정지하고 별도 실행 ID로 시행한다. 이 시험은 실측 센서를 가열하거나 임계값을 바꾸는 시험이 아니다.
