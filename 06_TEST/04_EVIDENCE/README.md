# 실제 시험 증거 보관

갱신일: 2026-10-22

실제 시험 증거는 RUN-20261017-01 아래에 보관한다. 이 이름은 자료 묶음 식별자이며 모든 시험이 2026-10-17 하루에 실행됐다는 뜻은 아니다. 개별 시험 시각과 세션은 03_RECORD/SIM_TEST_RECORD_R0.xlsx의 실행기록에서 확인한다.

| 하위 폴더 | 내용 |
|---|---|
| screens | SCADA, PLC, LabVIEW, ESP 모니터 등의 실제 캡처 |
| video | 조작, 이상 반응, 복구 및 종료를 기록한 영상 |
| csv | 검사 수락 결과 CSV |
| logs | 로그 및 당시 메모 |

원장의 증거목록에 증거ID, 실행ID, 프로젝트 최상위 폴더 기준 상대경로, 실제 확보시각과 확인 내용을 연결한다. 파일명을 변경하거나 위치를 옮기면 원장의 경로도 함께 수정한다. 실제 파일이 확인되지 않는 보조자료는 미보관 사실을 기록하며 존재하는 증거로 표시하지 않는다.

CSV의 검사 수락과 PLC의 배출 완료는 서로 다른 시점이다. 요청ID는 프로그램 재시작 후 반복될 수 있으므로 시험ID, CSV 파일명, 실행ID와 시각을 함께 사용한다. CSV 시각은 UTC, 실행기록과 보고서의 시각은 별도 표시가 없으면 KST다.

보관 자료의 추가 편집은 검토용 사본에서 수행하고 편집 또는 복구한 내역이 있으면 실행기록에 구분한다. 이미 기록된 편집 이력을 없었던 일로 바꾸지 않는다. 실패 또는 중단 자료도 기존 기록과 연결해 보존한다.
