# 시험 자료 보관 안내

작성일: 2026-10-22 / 작성 및 시험: 고진혁 / 기준선: BL-001

이 폴더는 반도체 후공정 검사 및 분류 프로젝트의 시험 계획, 실제 실행기록, 증거와 완료보고서를 보관한다. LS와 FX, 이송 및 분류 장치는 시뮬레이션이며 ESP32-S3와 SEN0137 온습도 센서 통신은 실제 시제품이다. 실물 PLC, 제어반, 기계 결선 및 안전 성능 검증은 포함하지 않는다.

## GitHub에서 읽기

[완료보고서 PDF](06_FINAL_PDF/SIM_COMPLETION_REPORT_R0_ko.pdf)로 완료 범위를 읽고, [시험 원장 PDF](06_FINAL_PDF/SIM_TEST_RECORD_R0.pdf)와 XLSX에서 개별 실행을 확인할 수 있다.

공개 저장소는 결과 문서, 소스, 대표 캡처와 [시험 영상의 압축 사본](04_EVIDENCE/RUN-20261017-01/video/encoded/)을 제공한다. 압축 사본은 열람용이며 원장에 기록된 원본 영상과 파일명 또는 크기가 다를 수 있다. 실행ID와 시험ID를 함께 대조한다. BL-001 전체 보관본과 원본 증거 영상은 로컬에 별도 보존하며 기본 공개 대상에서 제외한다. 따라서 원장의 일부 증거 경로는 공개 저장소에서 다운로드할 수 있는 파일이 아니라 로컬 보관 자료를 가리킨다. 공개 파일의 구체적인 포함 범위는 [저장소 소개](../README.md)를 확인한다.

## 현재 기록과 결과

* 실제 시험 기록 기간은 KST 2026-10-17 14:42:30부터 2026-10-22 01:10:00까지다. 하나의 연속 실행 시간이 아니다.
* 필수 시험은 P01-P17 및 AE01, AE02, AE05, AE08-AE12의 25건이며 최종 판정은 모두 합격이다.
* 선택 시험 AE06과 FX01은 이번 완료 범위에서 제외했고 합격 건수에 포함하지 않았다.
* 도면 검토 결과는 기능 기록 001-017의 대조완료 17건, 개념도 018-022의 개념검토완료 5건이다. 도면 개정은 R0다.
* 개념도는 CONCEPT / NOT FOR CONSTRUCTION 상태를 유지하며 실물 시험 합격을 뜻하지 않는다.

## 계획과 절차를 읽을 때

01_PLAN/SIM_TEST_PLAN_R1.md와 02_PROCEDURE/SIM_TEST_PROCEDURES_R1.md는 2026-10-15에 작성한 시험 전 계획 및 절차 이력으로 보존한다. 본문을 실제 결과에 맞춰 소급해서 합격 기록으로 고쳐 쓰지 않는다. 현재 결과를 읽을 때는 R0 원장과 완료보고서의 실행별 조건, 관측, 판정 범위를 함께 확인한다.

당시 문서와 최종 기록의 주요 차이는 다음과 같다.

* 과거 문서가 가리키는 SIM_TEST_RECORD_R1.xlsx의 현행 파일명은 SIM_TEST_RECORD_R0.xlsx다.
* 계획한 동일 CSV 연속 실행과 달리 일부 시험은 프로그램을 종료한 뒤 개별 세션으로 수행했다. AE05는 별도로 확보한 5건의 CSV와 이력 조회 결과를 사용한다.
* P17은 대기 시간을 시험 중 진행시켰다. 최종 판정은 알람103, 공정 차단 및 수동 복구 기능이며 설정 120초의 실제 경과시간 검증을 포함하지 않는다.
* AE11의 원래 목표는 30분 무중단 운전이었다. 최종 기록은 201건 생산, 검사 수락, 분류 및 CSV 정합 기능의 합격이다. 시험자 메모상 START부터 단발 전환까지는 29분 40초이며 OPC 및 중계 통신 안정성과 30분 무중단 목표는 합의한 판정 범위에서 제외했다. 단절 원인을 PC, Wi-Fi 또는 OPC 중 하나로 확정하지 않았다.
* 선택 AE06과 FX01은 미실시 참고 항목으로만 남아 있다. 구절차에 있다는 이유로 수행 완료 또는 합격으로 읽지 않는다.
* 과거 guide_ko.html 참조와 복사 잔여 문구는 당시 작업 안내의 흔적이다. 실제 실행기록이나 최종 발행 문서가 아니다.

02_PROCEDURE/DRAWING_CLOSEOUT_ko.md도 준비 단계 체크리스트로 보존한다. 빈 체크박스는 미검토라는 최종 판정이 아니다. 실제 검토 결과는 원장의 도면마감 탭과 최종 도면 001-022에서 확인한다. R100-R116은 001-017, P101-P105는 018-022의 이전 검토 ID다. 체크리스트의 예시 R1 및 예시 발행 상태를 실제 R0 도면에 다시 적용하지 않는다. 기능 도면의 실제 상태는 FUNCTION RECORD이고 개념도는 CONCEPT / NOT FOR CONSTRUCTION이다.

## 보관 시 주의할 연결

BL-001 기준선은 현재 작업 파일로 덮어쓰지 않는다. 증거 파일을 옮기거나 이름을 바꾸면 원장의 증거목록 경로도 갱신한다. 현재 파일을 확인하지 못한 보조자료는 미보관 사실을 메모하며 다른 자료로 몰래 대체하지 않는다. CSV 등을 추가로 편집할 때는 검토용 사본과 편집 내용을 구분한다.

이 README는 폴더를 설명하는 안내문이며 새로운 시험 결과, 고객 승인 또는 독립 인증을 추가하지 않는다.
