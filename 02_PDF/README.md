## 읽는 기준

001-017은 구현한 시뮬레이션 기능과 실제 ESP32 센서 통신을 기록한다. 018-022는 CONCEPT / NOT FOR CONSTRUCTION 상태로 남긴 실물 확장 개념 설계다. 시뮬레이션 시험 합격을 실제 기계나 안전회로의 성능 검증으로 해석하지 않는다.

`01_DRAFT`는 이전 도면 이력이다. 공개 저장소에서는 `02_FINAL`을 현재 검토 대상으로 사용한다. 도면의 구현 근거와 상세 판정은 [시험 원장과 완료보고서](../06_TEST/README.md)에 연결되어 있다.

편집 원본은 [CAD 폴더](../01_CAD/README.md), 도면 표의 원본은 [EXPORT 폴더](../03_EXPORT/README.md)에 있다. PDF의 제목, 주소 또는 단위를 변경할 때는 원본 DWG와 표도 함께 확인한다.
