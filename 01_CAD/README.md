# CAD 원본

AutoCAD Electrical 2027에서 정리한 도면 원본이다. 현재 완성 범위는 PLC 시뮬레이션과 실제 ESP32 온습도 센서 연동이며, 최종 도면 22장의 개정은 R0다.

도면을 검토하려면 PDF부터 읽고, 편집하거나 상세 객체를 확인할 때 DWG를 연다.

## 도면 범위

| 번호 | 구분 | 기록한 내용 |
|---|---|---|
| 001-017 | FUNCTION RECORD | 시스템 역할, 통신, 논리 I/O, 가상 안전, 공정 상태, ATE, 센서 프레임, 환경 판정, 화면과 시험 근거 |
| 018-022 | CONCEPT / NOT FOR CONSTRUCTION | 향후 실물의 전원, 하드웨어 안전, 물리 I/O, 패널 및 케이블 계획 |

018-022는 제작 승인 도면이나 실제 결선 검증 결과가 아니다. 실제 PLC, 모터, 실린더, 제어반 및 안전회로는 이번 프로젝트의 실물 시험 범위에 포함하지 않았다.

## 프로젝트 파일과 독립 도면

원본의 WDP/AEPX에는 과거 DRAFT 29장과 FINAL 22장이 함께 등록되어 있다.

원본 프로젝트를 재사용하려면 WDP/AEPX와 DRAFT 및 FINAL의 상대 경로를 함께 보존한다. FINAL 전용 프로젝트가 필요하면 작업 사본에서 새로 등록하고 원래 프로젝트는 별도로 보관한다.

`01_DRAFT`은 이전 설계 및 중간 변환 자료이며, 현재 최종 도면 목록에 포함하지 않는다. 이전 검토 ID R100-R116은 최종 001-017, P101-P105는 최종 018-022에 대응한다.

## 다른 환경에서 열기

글꼴, 외부 이미지 및 Excel 표 참조가 필요한지는 실제 DWG를 해당 환경에서 열어 확인한다. 표 원본은 `03_EXPORT/02_FINAL`에 보관한다. 공개 파일 목록의 존재만으로 모든 외부 참조가 자동 복구된다고 보장하지 않는다.
