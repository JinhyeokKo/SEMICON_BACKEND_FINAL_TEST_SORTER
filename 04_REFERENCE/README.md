# 참고 자료

외부 매뉴얼, 데이터시트와 참고 링크를 정리할 때 사용하는 폴더다.

현재 구현과 시험 결과를 확인하려면 다음 자료를 먼저 읽는다.

- [프로젝트 소개](../README.md)
- [최종 도면](../02_PDF/README.md)
- [시험 기록과 완료보고서](../06_TEST/README.md)

향후 외부 자료를 추가할 때는 문서명, 발행처, 버전 또는 확인일, 공식 출처 링크와 프로젝트에서 참고한 내용을 함께 기록한다. 원문을 재배포할 수 있는지 확인되지 않았다면 원문 파일 대신 출처 링크를 정리한다. 외부 참고자료 자체를 이 프로젝트의 구현 또는 시험 결과로 표시하지 않는다.
