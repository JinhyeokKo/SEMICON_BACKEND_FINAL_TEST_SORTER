# LS 공정 제어

XG5000에서 작성한 검사 및 분류 시퀀스다. XG-SIM 안에서 장치 응답을 모사하는 `SIM_IO`와 공정을 제어하는 `MAIN`을 함께 실행했다. 실제 컨베이어나 PLC 출력에는 연결하지 않았다.

## 시작 파일

| 파일 | 용도 |
|---|---|
| `SEMICON_SORTER.xgwx` | 시험에 사용한 LS 프로젝트 |
| `SEMICON_SORTER.state` | 편집기 상태 파일 |
| `*.xgwx_bkx*` | 이전 저장 백업 |

기록된 개발 환경은 **XG5000 4.78 / XG-SIM**이다. 최종 기능과 시험 결과는 [시험 원장 및 완료보고서](../06_TEST/README.md), 주소와 상태 흐름은 [최종 도면](../02_PDF/02_FINAL/)을 참조한다.

## 제어 구성

```text
SIM_IO: 제품 위치와 장치 응답, 안전 입력과 고장 입력을 모사
   ↓ 스캔 실행 순서
MAIN: 투입 → 검사 위치 → 클램프 → 가상 검사 요청·수락
      → PASS / FAIL / RETEST 게이트 선택 → 배출 → 계수
```

- `SIM_IO` 다음에 `MAIN`을 실행한다. 모델 상태와 공정 상태를 분리해 관리한다.
- 검사 요청과 응답 ID를 대조하고 PLC가 수락한 결과를 분류에 사용한다.
- 검사 수락 시점의 CSV와 배출 완료 시점의 생산 수량을 구분한다.
- STOP, 안전 입력 상실, 장치 고장에 따라 공정 출력과 복구 조건을 처리한다.
- 환경 허가는 새 사이클의 시작 조건이다. 환경 허가 상실 후에는 진행 중인 제품을 마무리하고 다음 사이클을 막는다.

## 주요 모드와 상태

| 항목 | 의미 |
|---|---|
| `D00053 = 0 / 1` | Auto / Manual. Manual은 사이클 금지와 조건부 수량 초기화이며 개별 Jog는 구현하지 않음 |
| `D01220 = 0 / 1` | 단발 / 연속 선택 |
| `M02100` | 새 START 후 PLC가 유지하는 연속 운전 기억 |
| `D00100` | MAIN 공정 상태 |
| `D01200` | SIM_IO 제품 위치 모델 |
| `D00300 / 302 / 304 / 306` | TOTAL / PASS / FAIL / RETEST의 32비트 수량 |

연속 선택만으로 기동하지 않는다. STOP, 안전 복구, RESET 또는 PLC RUN 재시작 후 자동으로 출발하지 않으며 준비 조건을 확인하고 새 START를 눌러야 한다. RETEST는 분류 결과이며 자동 재투입이나 반복 검사를 뜻하지 않는다.

## 실행 전 확인

1. XG5000에서 `SEMICON_SORTER.xgwx`를 연다.
2. 시뮬레이터와 CIMON의 LS 통신을 준비하고 프로그램 실행 순서를 확인한다.
3. 원시 입력을 정상으로 만들고 안전 복귀, 필요한 모델 정리, 공정 RESET을 순서대로 수행한다.
4. 환경 허가와 LabVIEW의 ATE 준비 상태를 확인한다.
5. 새 START로 시험을 시작한다.

설정값은 [기준설정과 시험 원장](../06_TEST/README.md)을 따른다. BL-001 전체 보관본은 로컬에 유지한다. 과거 시험 계획과 실제 수행 조건의 차이도 시험 자료 안내에 기록했다. 가상 안전 릴레이 로직은 시뮬레이션 정책이며 실물 안전회로의 성능을 검증한 것이 아니다.
